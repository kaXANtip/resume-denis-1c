# Резюме — Денис Исламов, Программист 1С

Адаптированная версия сайта-резюме под вакансии программиста 1С (Middle+).

## Что изменено (по ТЗ)

- Hero: должность, теглайн, пилюли → 1С-тематика
- Floating cards: BSL-код, метрика -80%, цепочка «Задача→Расширение→Продакшн»
- Value Prop: три блока переписаны под подход 1С-разработчика
- Кейсы c1–c9: 9 новых 1С-кейсов (УТ+БП, ЕГАИС, маркетплейсы, ЭДО, склад, СКД, Telegram, накладные, оптимизация)
- Порядок: c1–c3 featured, c4–c9 + mf1–mf3 + m1–m16 в сетке
- Skills: 1С-стек на первом плане
- Experience: «Программист 1С / Автоматизация»
- About: текст про 1С + Сколково
- Footer/title: «Программист 1С»
- Cursor bug fix: кастомный курсор не рендерится на touch-устройствах
- Mobile CSS: медиа-запросы для 480px

## Структура

```
my-resume-1c/
├── index.html              ← заголовок страницы обновлён
├── package.json
├── tsconfig.json
├── vite.config.ts
├── Resume 1C.html          ← ★ standalone-версия, открывается без сборки
├── resume-1c-data.js       ← данные для standalone
└── src/
    ├── main.tsx
    ├── App.tsx             ← все правки по ТЗ + cursor fix
    ├── data.tsx            ← новые кейсы c1–c9 добавлены
    └── index.css           ← мобильные медиа + cursor fix
```

## Запуск React-версии

```bash
npm install
npm run dev
```

Откроется на http://localhost:3000

## Standalone-версия

Откройте `Resume 1C.html` в браузере напрямую — никакой сборки не нужно.  
Файл `resume-1c-data.js` должен лежать рядом с `Resume 1C.html`.
